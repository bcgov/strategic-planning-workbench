# Living Strategic Planning Registers (`strategy/`)

This directory holds the team's living strategic planning artifacts and registers. Use the `strategic-planning` plugin skills (especially `updating-strategic-registers` and `rendering-strategic-visuals-and-decks`) to initialize, import, update, audit, and visualize these files over time.

## Canonical Register Index

|---|---|---|
| `00-planning-session-status.md` | Front-door session status & readiness scorecard across the 6 TOGAF ADM-aligned stages (`01`–`11`), open assumptions (`ASM-X`), pending promotion gates (`IDEA-X`), active dispensations (`DSP-X`), and next recommended step | `running-strategic-planning-cycle/assets/templates/planning-session-status.md` |
