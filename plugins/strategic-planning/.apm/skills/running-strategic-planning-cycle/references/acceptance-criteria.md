# Acceptance criteria: running-strategic-planning-cycle

1. **Readiness scan first**: Checks `strategy/00-planning-session-status.md` and `strategy/01`–`11` before asking intake questions, summarizing what is already recorded vs. missing.
2. **Plain-language 5-option entry menu**: Offers Top-Down, Bottom-Up/Middle-Out, Resume/Readiness Check, Meeting Note Ingestion, and Fast-Track Briefing options so business users do not need to memorize skill names.
3. **TOGAF ADM stage traceability**: Maps progress across the 6 workbench stages (ADM Preliminary/Phase A through Phase H) without exposing heavy jargon unless requested.
4. **Persistent session status (`strategy/00-planning-session-status.md`)**: Updates register status, open assumptions (`ASM-X`), pending idea promotion gates (`IDEA-X`), active strategic dispensations (`DSP-X`), and the next recommended action.
5. **B.C. Government Design System formatting**: Uses sentence-case headings and table labels, plain direct language, zero emoji, and `<br>` tags inside Mermaid boxes.
