# Aligning strategy and portfolio

Guides users interactively to audit end-to-end traceability (`Province / Ministry / CSB / Division` $\rightarrow$ `Team vision` $\rightarrow$ `Objectives` $\rightarrow$ `Capabilities` $\rightarrow$ `Ideas` $\rightarrow$ `Committed work` $\rightarrow$ `Measures`) and assess strategic, policy, privacy, and delivery risks.

## Constraints

1. **Interactive decision walkthrough**: Present alignment findings and portfolio anomalies clearly, then walk the user through numbered decision options (`Realign`, `Justify as operational baseline`, `Consolidate duplicates`, `Pause/Retire`, or `Commission discovery`) rather than making unilateral portfolio cuts.
2. **Evidence-based gap detection**: Never invent synthetic links; explicitly highlight orphaned work, unsupported objectives, and unaddressed capability gaps.
3. **B.C. Government Design System style**: Use sentence case for headings and labels, plain language, zero emoji, and confirm changes via a recap gate before saving.

## Quick start

1. Read [alignment-and-risk-guide.md](references/alignment-and-risk-guide.md) for the 8 diagnostic checks and public-sector risk taxonomy.
2. Present the alignment findings and interactive resolution options, then populate [alignment-traceability-matrix.md](assets/templates/alignment-traceability-matrix.md) and [strategic-risk-register.md](assets/templates/strategic-risk-register.md).

## Workflow

1. **Trace the Full Chain**: Map multi-tier mandates $\rightarrow$ `OBJ-X` $\rightarrow$ `CAP-X` $\rightarrow$ `IDEA-X` $\rightarrow$ `WORK-X` $\rightarrow$ `MSR-X`.
2. **Present the 8 Alignment Diagnostics**: Show the user where work is orphaned, objectives lack backing, capability gaps are unaddressed, or duplicate efforts exist.
3. **Interactive Resolution Choices**: For each gap or conflict, offer a numbered option menu so the user can decide how to resolve or escalate it to leadership.
4. **Guided Risk Assessment**: Walk through strategic, policy/legislative, privacy/security, judicial independence, workforce, and dependency risks using [strategic-risk-register.md](assets/templates/strategic-risk-register.md).
5. **Recap Gate & Hand Off**: Confirm decisions before updating `strategy/09-alignment-traceability-matrix.md` and `strategy/06-constraints-assumptions-risks.md`, then offer to chain to `sequencing-roadmaps-and-measures` or `rendering-strategic-visuals-and-decks`.
